proyecto `C:\Users\Fito\Documents\CODEX\SARA`: las declaraciones de gastos y

WhatsApp, plataforma visual ni runtime remoto.

## Contrato de uso desde Codex

1. Una declaración inequívoca de gasto (`gasté`, `pagué`, `anotame un gasto`)
   se registra; `BUSINESS` requiere empresa y la ambigüedad se aclara sin escribir.
2. `recordá`, `guardá` o `tené en cuenta` guarda contexto durable no sensible.
3. Contexto sensible requiere explicar qué se guardará y obtener consentimiento.
4. Conversación ordinaria se usa de forma efímera y no se persiste.
5. Datos prohibidos se rechazan antes de archivos, logs o respuestas persistidas.
6. `olvidá` elimina el valor y deja solamente auditoría no reveladora.
7. Casos personales se abren o actualizan únicamente con intención clara.
8. Toda mutación devuelve JSON con `ok`, `action`, `id` y `persisted`.
